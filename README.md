# Juegos sin propaganda

Juegos simples para chicos, sin publicidad, sin compras y sin juntar datos.

- 🏍️ Moto 3D: arranca con un toque, salta sola, se maneja deslizando el dedo.
- 🛻 Lavadero: elegí un vehículo, enjabonalo, enjuagalo con la hidrolavadora y pintalo.
- 🚗 ¿Dónde está?: aprender los colores con autos.

Jugar: https://nicosorroquieta.github.io/juegos-sin-propaganda/
